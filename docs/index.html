The gap between a backtest

Most frameworks model the signal and wave at the execution. pwb-toolbox models commissions, slippage and broker-specific fills as first-class citizens — then hands you the same tearsheet metrics whether the equity curve came from a backtest or from a live account.

Load, run, measure

The whole loop, minus the strategy class itself.

import pwb_toolbox.datasets as pwb_ds
import pwb_toolbox.backtesting as pwb_bt
from pwb_toolbox.performance import sharpe_ratio, max_drawdown, calmar_ratio

# Daily bars, split- and dividend-adjusted by default.
df = pwb_ds.load_dataset(
    "Stocks-Daily-Price",
    ["AAPL", "MSFT"],
)

# Pulls the data, wires the engine, attaches broker + strategy, runs it.
equity = pwb_bt.run_strategy(DualMomentum, df, cash=100_000)

# The same functions accept a live account's equity series.
print(sharpe_ratio(equity), max_drawdown(equity), calmar_ratio(equity))
